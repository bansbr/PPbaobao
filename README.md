# 小芽日记 · 宝宝成长记录系统 — 项目介绍

> 本文依据项目源码与配置文件整理，涵盖功能、部署与使用指南。  
> 文中涉及的生长曲线、疫苗程序、里程碑等均为公开参考资料与家庭记录工具，**仅供家庭参考，不构成医疗建议**。

---

## 一、项目简介

**小芽日记**（内部名称 `baby-journal`）是一套可自托管的家庭宝宝成长记录系统，把喂养、睡眠、排泄、生长、医疗、童言等分散信息集中管理，并用 WHO 儿童生长标准做可视化参考。系统部署在自建服务器/NAS 上，数据存于本机 SQLite 数据库，支持多账号与档案级协作权限，适合多位照护者共同记录。

- **数据存储**：自建服务器 SQLite 数据库（默认 `data/baby-journal.db`），无第三方上传、无云同步。
- **访问方式**：浏览器访问本机服务，前端零构建、随服务一并托管。
- **账号体系**：公开注册关闭，由系统管理员统一创建账号并分配档案权限。

## 二、核心功能

### 1. 今日概览

按日汇总喂养次数/奶量/亲喂时长、睡眠时长与夜醒次数、排泄次数、最近一次生长数据、最新童言、里程碑与接种计数，并根据月龄给出**待接种疫苗提醒**。

### 2. 十二类日常记录

| 类别    | 说明                                 |
| ----- | ---------------------------------- |
| 喂养    | 亲喂/瓶喂/配方奶/辅食/水等，记录奶量、时长、首次引入过敏原与反应 |
| 睡眠    | 夜间/小睡/夜醒，时长、夜醒次数、质量                |
| 大小便   | 类型、量、颜色性状，可附**压缩照片**               |
| 黄疸    | 数值、部位、程度、是否消退                      |
| 生长    | 体重、身长/身高、头围                        |
| 里程碑   | 达成时间对照与自定义项                        |
| 接种    | 疫苗、剂次、接种门诊、批号、反应                   |
| 儿保    | 体检机构、月龄、体格数据、小结与医嘱                 |
| 用药    | 药品、剂量、起止时间、原因                      |
| 过敏史   | 过敏原、反应、程度、状态                       |
| 过敏原引入 | 引入食物、反应（喂养记录标记「首次引入」时**自动联动写入**）   |
| 童言童语  | 内容、场景、说话人、标签                       |

所有记录支持新增、编辑、删除；首页提供快捷入口。写入统一经字段白名单校验（类型、范围、枚举、图片 data URL 格式），杜绝非法数据入库。

### 3. WHO 生长曲线与评估

- 数据源：**WHO Child Growth Standards (2006)** LMS 扩展表，覆盖 0–60 月龄。
- 指标：体重、身长/身高、头围；展示 P3 / P15 / P50 / P85 / P97 五条百分位参考线与实测折线。
- 评估：按 LMS 法计算 z 值与百分位、所处区间（band）；低于 P3 / 高于 P97 标为预警，z 值下降给出提示。
- 早产校正：根据预产期与出生日期之差计算校正天数，用于月龄换算。

### 4. 发育里程碑

内置 13 项常见里程碑（抬头、翻身、独坐、爬、扶站、独走等）及月龄参考窗口，可登记达成时间并自定义条目。窗口为国内儿保常用参考区间，**非诊断标准**。

### 5. 医疗档案

五个页签（接种 / 儿保 / 用药 / 过敏史 / 过敏原引入）。疫苗程序参考《国家免疫规划疫苗儿童免疫程序（2021 版）》整理，自费苗单列，实际接种以当地门诊为准。

### 6. 多用户协作

- 系统管理员**统一创建账号并分配档案权限**，公开注册已关闭。
- 每个宝宝档案三种角色：`owner`（档案管理员）/ `editor`（可写）/ `viewer`（只读）。
- 有约束保护：任何档案至少保留一名 owner；系统至少保留一名可用管理员；改密码或停用账号会立即失效其会话。

### 7. 备份与恢复

- 导出为 **v2 可移植 JSON 备份包**：含档案配置、全部记录、协作成员名单与原始记录人；照片以 base64 内嵌。
- 导入三种模式：`create`（新建档案恢复，默认）、`replace`（覆盖）、`merge`（按内容指纹去重追加）。
- 兼容早期 v1 备份；导入时按用户名重建协作关系，本机不存在的账号会列出提示补邀请。

### 8. 主题与照片

5 种主题色（pink / amber / mint / purple / lemon），跟随当前宝宝切换；大小便记录可附前端压缩后的照片。

## 三、部署指南

### 3.1 Docker Compose（推荐）

```bash
# 在项目根目录执行
docker compose up -d --build
# 浏览器访问
# http://localhost:3000
```

- 首次启动自动建库并创建初始管理员，数据写入命名卷 `baby-data`，升级镜像不丢数据。
- 若想直接看到宿主机上的数据库文件，可将卷改为绑定挂载 `./data:/app/data`（先确保目录存在）。
- 拉取镜像/依赖困难时，用环境变量 `NODE_IMAGE`、`NPM_REGISTRY` 覆盖镜像源与 npm 源（见 `docker-compose.yml`）。

### 3.2 本地 Node 运行

前置：Node.js 22.5–22.x（内置 `node:sqlite`；npm 脚本已带 `--experimental-sqlite`）。

```bash
npm ci          # 安装依赖
npm start       # 启动，访问 http://localhost:3000
# 开发调试可用 npm run dev（文件变更自动重启）
```

自检命令：

```bash
npm run check     # 语法检查
npm run smoke     # 接口冒烟测试
npm run ui:check  # 界面检查
```

### 3.3 环境变量

| 变量                                  | 默认值                         | 说明                    |
| ----------------------------------- | --------------------------- | --------------------- |
| `PORT`                              | `3000`                      | 监听端口                  |
| `HOST`                              | `0.0.0.0`                   | 监听地址                  |
| `DATA_DIR`                          | `./data`                    | 数据目录（容器内 `/app/data`） |
| `DB_PATH`                           | `$DATA_DIR/baby-journal.db` | 数据库文件路径               |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 见 `docker-compose.yml` 注释   | 首次启动的初始管理员账号密码        |
| `TZ`                                | `Asia/Shanghai`             | 时区                    |
| `NODE_IMAGE` / `NPM_REGISTRY`       | 官方默认                        | 构建镜像源与 npm 源          |

> **初始管理员**：仅在系统没有任何管理员时创建（或把已有账号提升为管理员），重启不会覆盖已有账号与密码。默认初始账号见 `docker-compose.yml` 注释，**首次登录后请立即在「设置与协作 → 账号安全」修改密码**；生产部署建议直接用环境变量设置强密码。

### 3.4 升级与数据持久化

- 数据库结构做了幂等升级，旧版本库启动时会自动补齐新增列，既有账号与记录不受影响。
- 升级前建议在「设置与协作」导出一份 JSON 备份留档。

## 四、使用指南

1. **首次登录**：用初始管理员账号登录，进入「设置与协作 → 账号安全」立即改密。
2. **创建账号**：系统管理员进入「用户管理」，创建账号并分配昵称、角色与各宝宝档案权限。
3. **新建档案**：填写宝宝昵称、出生日期、性别、预产期（用于早产校正）、主题色。创建者自动成为该档案 `owner`。
4. **日常记录**：在对应记录页新增/编辑/删除，或使用首页快捷入口；大小便记录可拍照。
5. **生长曲线**：切换体重/身长/头围、月龄范围（0–12 / 24 / 36 / 60 月），查看百分位线与偏离提示。
6. **里程碑 / 医疗档案**：按月龄对照里程碑并登记；在医疗档案登记接种、儿保、用药、过敏信息，首页会提示待接种疫苗。
7. **协作**：owner/editor 可写，viewer 只读；管理员可在用户管理调整权限。
8. **备份**：在「设置与协作 → 备份」导出 JSON 下载留档；换机/恢复时用导入，按需选择 create / replace / merge。

## 五、数据安全与隐私

- 数据默认留在自建服务器，无第三方上传、无云同步。
- 密码以 scrypt 加盐哈希存储，会话 token 仅存哈希；Cookie 设置 `HttpOnly` 与 `SameSite=Lax`。
- 备份 JSON 含全部数据（含照片），请妥善保管，避免外泄。
- 应用内的生长评估、里程碑、疫苗提醒为参考性提示，**仅供参考，不构成医疗建议**，健康问题请以接种门诊/儿保医生意见为准。

---

## 六、注意事项

- **Node 版本**：依赖 Node 22 内置的 `node:sqlite`，请用 22.5–22.x；低版本无法运行。
- **初始密码**：默认账号仅用于首次登录，务必及时修改为强密码。
- **数据备份**：本地数据有丢失风险，养成定期导出 JSON 的习惯。
- **医疗定位**：本工具是记录与可视化工具，不提供诊断或治疗建议。
